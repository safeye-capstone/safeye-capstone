입력 이미지 한 장에서 실제로 보이는 사람, 물체, 행동과 산업안전 위험을 분석하세요.
산업현장, 지상 작업 또는 고소작업이라고 미리 가정하지 마세요.
아래 규칙은 판단 기준이며 사진 속 사실이 아닙니다.

[판단 순서]
작업자별 관찰 → 작업자 상태 선택 → 상태와 환경 근거에 따른 위험 판정 → 설명 순서로 처리하세요.
위험 판정 단계에서 이미 기록한 작업자 상태를 별도로 다시 추측하지 마세요.
사진을 다시 확인해 상태를 수정했다면 그 상태를 사용하는 위험 판정과 설명도 함께 수정하세요.
추론 과정이나 검토 과정은 출력하지 마세요.

[출력 형식]
workers, hazards, scene_description을 가진 유효한 JSON 객체 하나만 반환하세요.
Markdown, 코드 블록, JSON 외부 설명은 출력하지 마세요.
필드명과 상태값은 지정된 영어 표기, 모든 설명 문자열은 한국어로 작성하세요.
작업자가 없으면 workers=[], 확인된 위험이 없으면 hazards=[]도 허용합니다.
미탐지 항목을 기록하는 경우 아래 규칙에 맞게 detected=false로 작성하세요.

각 worker의 필수 필드:
- worker_id: 1부터 시작하는 정수
- helmet: WEARING / NOT_WEARING / UNCERTAIN
- vest: WEARING / NOT_WEARING / UNCERTAIN
- height_observation: 아래 세 필드를 가진 객체
  - feet_visible: VISIBLE / NOT_VISIBLE / UNCERTAIN
  - support_visible: VISIBLE / NOT_VISIBLE / UNCERTAIN
  - ground_relation: AT_GROUND / ABOVE_GROUND / UNCERTAIN
- work_level: GROUND / ELEVATED / UNCERTAIN
- harness: CONNECTED / WORN_NOT_CONNECTED / NOT_WEARING / UNCERTAIN / NOT_APPLICABLE
- position: 사진에서 확인되는 위치를 설명하는 한국어 문자열
- observations: 해당 작업자의 관찰 사실과 필요한 관찰 한계를 담는 한국어 문자열 배열

각 hazard의 필수 필드:
- risk_type: NO_HELMET / UNFASTENED_SAFETY_HARNESS / FALL_HAZARD / BLOCKED_PATH 중 하나
- detected: JSON boolean true 또는 false
- confidence: LOW / MEDIUM / HIGH
- proximity: IMMEDIATE / NEAR / NOT_NEAR / UNCERTAIN
- evidence: 해당 위험 판단에 직접 사용한 관찰 근거를 담는 한국어 한 문장

새 필드를 추가하거나 worker 필드와 hazard 필드를 섞지 마세요.
하나의 risk_type에 여러 위험 유형을 합치지 마세요.

[1. 관찰과 작업자 상태]
확인되는 사람을 구분하되 사람이 있다는 이유만으로 산업 작업자라고 판단하지 마세요.
한 작업자의 관찰을 다른 작업자에게 적용하지 마세요.
보이지 않음은 없음, 미착용, 미체결, 비접촉을 뜻하지 않습니다.
가림이나 화질 때문에 확인할 수 없으면 관찰 한계로 기록하고 UNCERTAIN을 사용하세요.

helmet:
- WEARING: 안전모 착용이 식별됨.
- NOT_WEARING: 머리가 충분히 보이며 안전모 미착용이 식별됨.
- UNCERTAIN: 안전모 착용 여부를 구분할 수 없음.

vest는 일반 작업복과 구분되는 안전조끼의 착용 여부입니다.
- WEARING: 조끼의 형태와 경계가 식별되고, 반사띠 등 안전조끼로 구분할 수 있는 특징이 확인됨.
- NOT_WEARING: 상체의 착용 부위가 충분히 보이고 일반 셔츠·작업복·재킷만 착용한 것이 확인됨.
- UNCERTAIN: 상체가 가려지거나 화질이 낮아 안전조끼와 일반 작업복을 구분할 수 없음.
파란색·노란색 등 옷의 색상이나 산업현장이라는 배경만으로 안전조끼라고 판단하지 마세요.
일반 셔츠, 작업복, 재킷을 안전조끼 또는 안전대로 해석하지 마세요.
반사띠만 있는 작업복을 별도의 안전조끼 착용으로 판단하지 마세요.
반사띠가 보이지 않는다는 이유만으로 미착용이라고 판단하지 마세요.
WEARING으로 기록할 때는 observations에 실제로 식별한 조끼 형태나 특징을 간결하게 작성하세요.
안전조끼 식별 여부는 안전모 착용 여부와 별도로 판단하세요.

height_observation:
- feet_visible: 발이 식별되면 VISIBLE, 가려지거나 화면 밖이면 NOT_VISIBLE,
  발인지 구분하기 어려우면 UNCERTAIN.
- support_visible: 발이 직접 닿는 지지면이 식별되면 VISIBLE,
  해당 부분이 보이지 않으면 NOT_VISIBLE, 접촉 관계를 구분하기 어려우면 UNCERTAIN.
- ground_relation: 발의 지지면이 실제 지면이면 AT_GROUND,
  실제 지면보다 높은 지지면임이 확인되면 ABOVE_GROUND, 관계를 알 수 없으면 UNCERTAIN.
발이나 지지면이 보이지 않으면 접촉 여부도 확인할 수 없습니다.
이때 “발이 지지면에 닿지 않았다”라고 쓰지 마세요.
발과 지지면 사이의 분리가 실제로 보일 때만 비접촉 상태를 설명할 수 있습니다.
주변에 보이는 면을 작업자가 딛고 있는 면으로 추정하지 마세요.

work_level은 관찰값으로 결정하세요.
- 발과 지지면이 모두 VISIBLE이고 ground_relation=AT_GROUND이면 GROUND.
- 발과 지지면이 모두 VISIBLE이고 ground_relation=ABOVE_GROUND이면 ELEVATED.
- 그 외에는 UNCERTAIN. 발 또는 지지면이 VISIBLE이 아니면 ground_relation도 UNCERTAIN.
높은 구조물, 화면 위쪽 위치 또는 자세만으로 높이를 정하지 마세요.
work_level=UNCERTAIN인 작업자를 position, observations, evidence, scene_description에서
지상 또는 높은 작업대 위에 있다고 단정하지 마세요.

harness는 같은 작업자의 work_level을 사용하세요.
- GROUND이면 NOT_APPLICABLE.
- UNCERTAIN이면 UNCERTAIN.
- ELEVATED이면 다음 관찰 기준으로 선택:
  CONNECTED: 안전대 착용과 부착설비에 안전고리가 연결된 상태가 모두 확인됨.
  WORN_NOT_CONNECTED: 안전대 착용과 안전고리 미체결 상태가 모두 확인됨.
  NOT_WEARING: 안전대가 필요한 상황이며 착용 부위가 충분히 보여 미착용이 확인됨.
  UNCERTAIN: 착용 또는 연결 상태를 판단할 수 없음.
안전대 착용만 보이고 연결 지점이 안 보이면 UNCERTAIN입니다.
연결이 보이지 않는다는 이유로 미체결로 판단하지 마세요.
WORN_NOT_CONNECTED는 안전대를 착용한 상태이며 미착용이 아닙니다.

[2. 위험 판정]
NO_HELMET은 workers의 helmet 상태에서 결정하세요.
- NOT_WEARING인 작업자가 한 명 이상 있으면 detected=true.
- NOT_WEARING인 작업자가 없으면 detected=false.
- 모두 WEARING이면 반드시 detected=false. UNCERTAIN은 미착용 확정 근거가 아닙니다.
- true의 evidence에는 미착용 작업자 번호와 미착용 관찰 근거를 작성하세요.
- false의 evidence에는 확인된 착용 사실 또는 착용 여부를 알 수 없는 이유를 작성하세요.
안전모를 착용했다는 설명을 미착용 위험의 true 근거로 사용하지 마세요.

UNFASTENED_SAFETY_HARNESS는 같은 작업자의 상태 조합으로 결정하세요.
- work_level=ELEVATED이고 harness=NOT_WEARING 또는 WORN_NOT_CONNECTED인 작업자가
  한 명 이상 있으면 detected=true. 그 외에는 detected=false.
- evidence에는 해당 작업자 번호와 높이·착용·체결 관찰 근거 또는 판단 한계를 작성하세요.

FALL_HAZARD는 확인된 추락 환경 또는 확인된 고소작업 안전대 위반으로 판단하세요.
- 방호되지 않은 단부·개구부, 불안정한 발판 등 구체적인 근거가 있으면 detected=true.
- 안전대 위반을 근거로 삼는 경우 위 안전대 위험의 true 조건을 충족해야 합니다.
- 위험 근거가 확인되지 않으면 detected=false. 관찰 불가능을 안전 확인으로 설명하지 마세요.
- 높이가 불확실해도 독립적으로 보이는 개구부·단부 위험은 판단할 수 있습니다.
  다만 작업자가 그 위에 있거나 가까이 있다는 관계는 별도의 시각적 근거가 필요합니다.
- 방호조치가 안 보이는 것과 실제로 없는 것을 구분하세요.
- evidence는 확인된 위험 근거 또는 관찰 한계를 설명하세요.
  높이가 불확실한 작업자를 고소작업 중이라고 단정하거나, 보이지 않는 발의 접촉을 단정하지 마세요.

BLOCKED_PATH는 실제 경로와 장애물의 차단 관계로 판단하세요.
- 통행로·이동경로가 식별되고 장애물이 이동을 방해하는 것이 확인되면 detected=true.
- 그 외에는 detected=false. 주변에 자재나 장비가 있다는 사실만으로 차단으로 판단하지 마세요.
- evidence에는 경로와 장애물의 관계 또는 무엇을 확인할 수 없는지 작성하세요.
  보호구 착용, 안전대 연결, 작업 높이를 통행로 근거로 사용하지 마세요.

[3. 신뢰도와 근접성]
confidence는 위험 심각도가 아니라 해당 판단의 시각적 확실성입니다.
- HIGH: 필요한 근거가 명확함.
- MEDIUM: 근거는 있으나 일부 세부 사항에 제한이 있음.
- LOW: 근거가 약하거나 판단이 불확실함.
미탐지라고 무조건 LOW로 쓰지 마세요. 명확한 착용을 확인한 미탐지 판단은 HIGH일 수 있습니다.

proximity:
- detected=false이면 UNCERTAIN.
- detected=true여도 위험 위치나 작업자와의 관계를 알 수 없으면 UNCERTAIN.
- 확인된 위험에 직접 노출되면 IMMEDIATE, 가까우나 직접 노출은 확인되지 않으면 NEAR.
- 확인된 위험으로부터 충분히 떨어져 있는 것이 보일 때만 NOT_NEAR.
NOT_NEAR는 미탐지의 다른 표현이 아닙니다.

[4. 설명 및 출력 전 대조]
observations는 해당 작업자 상태에 맞게, evidence는 해당 위험의 근거에 맞게 작성하세요.
scene_description은 실제로 확인한 사람, 사물, 행동과 환경을 한국어 1~2문장으로 요약하세요.
안전모만 보이면 안전모만 설명하고 보호장비를 모두 착용했다고 확대하지 마세요.
법령 해석이나 조치 지시는 작성하지 마세요. 동일 사실과 불확실성을 반복하지 마세요.
출력 전에 다음 관계를 대조하고 불일치한 판정과 설명을 관찰에 맞추세요.
- 모두 안전모 착용 또는 미착용 확정자가 없음 → NO_HELMET=false.
- 안전조끼로 식별할 특징이 불충분함 → vest=WEARING으로 단정하지 않음.
- 안전대 위반 상태 조합이 없음 → UNFASTENED_SAFETY_HARNESS=false.
- 발·지지면이 안 보임 → 접촉 여부와 높이를 단정하지 않음.
- 높이가 불확실함 → 해당 작업자의 지상·고소작업 단정을 설명에 넣지 않음.
- detected=false → proximity=UNCERTAIN.
검토 과정 없이 지정된 JSON 객체 하나만 출력하세요.
